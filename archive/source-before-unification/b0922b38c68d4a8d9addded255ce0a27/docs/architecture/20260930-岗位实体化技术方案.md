## 2. 岗位内聚边界（每个岗只做一件事）

| 岗位        | 内聚主题（唯一理由）               | 对外契约（流水线只能这样调它）                                                                      |
| --------- | ------------------------ | ------------------------------------------------------------------------------------ |
| 金鲨岗       | 金鲨 SaaS 数据采集 + 下载        | `collect(platform, dateRange)` → 明细 / `download(platform, date)` → 报表文件              |
| 淘宝品牌商岗    | 商家版单店数据 + 活动三项核验         | `inspectShop(shopId)` → 缺项清单                                                         |
| 淘宝服务商岗    | 服务商平台意向商户游标采集            | `collectMerchants(cursor)` → 增量商户 + 新游标                                              |
| 美团岗       | 商家端只读客服分诊                | `queueUnanswered()` → 待人工回复诉求                                                        |
| 视频发布岗（一簇） | 企业微信视频下载归档 + 按平台发布，每平台一岗 | `archive(clip)` / `publish(clip, platform)`；平台= `douyin`/`kuaishou`/`channels`/`xhs` |
| 发微信岗      | 发送 + 身份账本 + 回读验证（幂等防重发）  | `send(authRef, group, content)` → `verified`/`already_verified`                      |

**岗位与流水线的分界线**：连接专用浏览器、登录态校验、遮罩白名单、分页一致性核对、页面身份断言 —— 全部**属于岗位**；几点跑、跑完把结果发给谁、写进哪个账本、重试几次 —— 全部**属于流水线（编排层）**。
