# 双平台四店本地试巡方案

## 模板纠偏（2026-09-09）

- 唯一业务模板为 `runtime/门店自检表(框架+模板).xlsx`，原始来源为用户提供的 `/Users/ddt/work/臻肆/工作流/门店自检表(框架+模板).xlsx`。
- 巡店范围必须逐行来自模板的“项目”列，不得由页面上临时看到的评分、月售、评价等信息替代或新增巡店项目。
- 每个模板项目必须原位保留；实际发现的问题写入该项目对应的“注意事项”，并在相邻方案字段写出可执行的具体方案。没有证据时按模板约定标记缺失或待核验，禁止猜测。
- 结果工作簿以模板的工作表、列顺序、项目顺序和样式为基线；仅填入门店身份、巡店日期、对应注意事项、具体方案和证据字段。
- 原先自定义的四表结果结构作废。旧的四份结果移入可恢复废纸篓后，必须重新真机巡店并按模板生成。

## 范围

- 本轮仅完成淘宝闪购 2 家、美团外卖 2 家上海门店。
- 本轮选择双平台可对照、且在消费者端能够按同一商圈稳定复验的两家：`9家湘菜（金谊广场店）`、`陶姥姥砂锅·广式啫啫煲（金谊广场店）`；平台标点差异按全半角括号归一化，核心店名不得模糊匹配。
- 原候选 `阿达西烤肉（花木店）` 在淘宝闪购当前检索中只出现名称不一致的 `阿达西烤肉（银霄路店）` 到店团购页，不能当作目标外卖门店；已按“目标店名不能确认则终止该店”处理，不纳入本轮结果。
- 只生成本地巡店结果，不上传企业微信，不回写周台账为已完成。

## 控制与安全

- 手机控制唯一通道为物理 Honor 设备的 ADB/uiautomator2；每次动作后重新读取当前页面，旧坐标和旧控件立即失效。
- 优先 UI 树文字/描述定位；WebView 未暴露语义节点时才用当前截图的相对区域点击，并用下一帧店名或页面标题复验。
- 全程只读。禁止领券、收藏、加购、下单、联系商家及任何提交动作。
- 同一节点最多一次恢复；目标店名或城市不能确认时终止该店，不以近似结果代替。
- 消费者端搜索受配送地址约束时，先用门店所在商圈的精确 POI 切换收货地址，再搜索完整店名；地址切换后必须在搜索页看到新 POI 文本才继续。

## 每店证据节点

1. 搜索结果：城市、完整店名、评分/月售/配送等当前可见字段。
2. 商品页：分类、主要商品、价格带、促销和页面滚动覆盖。
3. 评价页：评分、评价量、可见正负评价、商家回复；无可验证差评则明确记录。
4. 商家页：营业时间、地址、配送、证照/标签等当前可见字段。
5. 对消费者端不可见的经营、补贴、复购等字段在结果中留空。

## 输出合同

- 结构化中间证据：`runtime/pilot-evidence/<平台>-<门店>/inspection.json` 与截图。
- 每店一份 Excel：`runtime/results/2026-09-第2周/<平台>-上海市-<门店>-巡店结果.xlsx`。
- 每店结果必须从 `runtime/门店自检表(框架+模板).xlsx` 复制并填充，工作表和巡店项目以模板为准，不再生成自定义四表结构。
- 所有事实必须有截图文件或页面字段来源；建议和事实分栏，不将推测写成结论。
- 四份 Excel 生成后做结构检查与页面渲染检查；本轮随后暂停等待用户验收。

## 验收与停止条件

- 4 家均完成店名/城市复核，且商品、评价、商家信息至少各有一份当前页面证据。
- 文件名、四张表、目标门店和平台一致；不存在空结果或跨店证据串用。
- 若平台页面升级导致某一分区无法进入，保留已验证事实，其余字段留空，不得伪造；若连目标店都无法确认，则该店不生成“已完成”结果。

## 2026-09-10 稳定执行改造方案

### 证据呈现口径补充（2026-09-10）

- 截图只用于巡店过程中的事实复核；若不随结果工作簿一并留存，不在面向门店的 Excel 中展示截图文件名或“证据：xxx.png”文本。
- 结果表仅保留“检查点”和“巡店发现”；事实仍必须来自已核验页面，但不把未交付的文件路径当作可供客服索取的附件。

### 目标与范围

把本次上海四店真机回归中已验证的身份门禁和导航链路固化为可校验配置与确定性底层动作。改造只影响本地 `store-inspection` Skill、执行器、测试和本地结果文件；不操作商家后台、企业微信、巡店台账或任何交易入口。

### 固定身份合同

- 唯一 POI：`中房金谊广场`，地址消歧锚点为上海市浦东新区上南路 4467 号。
- 淘宝闪购目标：`9家湘菜（金谊广场店）`、`陶姥姥砂锅·广式啫啫煲（金谊广场店）`。
- 美团外卖目标：`9家湘菜（金谊广场店）`、`陶姥姥砂锅菜（金谊广场店）`；后者仅允许与台账名发生已经验证的“广式啫啫煲”到“砂锅菜”名称口径漂移，且必须同时命中金谊广场 POI 与商家地址锚点。
- 输入店名后，只有搜索结果、POI、商家页地址三者互相一致才允许进店；到店团购、其他分店、错误城市或仅名称相似均失败关闭。

### 固定状态机与恢复

1. `preflight` 只接受唯一物理 Honor 设备；主微信前台确认仅为预检，不读取聊天内容。
2. 平台 App → 外卖/闪购频道 → 当前 POI → 完整店名搜索 → 唯一搜索结果 → 商品首页 → 商品下翻 → 评价/差评 → 商家页。
3. 每次点击前重新截图/OCR；优先文本锚点，OCR 合框、重复命中、输入框失焦均立即失败关闭，不复用旧坐标。
4. 验证码由用户关闭后，重新取当前帧；不输入、识别、绕过验证码。若评价区仍为网络错误，评论模块可以留空，但继续商品、商家等独立分区。
5. 同一页面节点最多一次恢复，恢复后仍失败则记录页面错误收据并继续未受影响的独立分区；不重试未知动作。
