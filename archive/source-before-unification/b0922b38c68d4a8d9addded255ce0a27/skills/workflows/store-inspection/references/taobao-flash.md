# 淘宝闪购巡店

## 已验证路径

1. 启动 `com.taobao.taobao` 并确认淘宝在前台。
2. 进入闪购频道；消费者端按配送范围返回结果，先从搜索页切换到目标商圈的精确收货 POI，再输入完整店名。
3. 从地址候选中选择同时满足城市、区县和门牌号的 POI；返回搜索页后必须看到顶部 POI 已更新。
4. 在搜索结果页输入完整店名；通过店名、距离、评分、月售和地址上下文消歧。
5. 进入店铺，遍历菜单、评价、商家资料；对分类侧栏和内容区分别滚动。

淘宝页面升级后不得依赖旧坐标。优先使用文本、控件树和页面上下文；OCR 命中必须二次验证。
