# 微信主窗口尺寸过滤方案

## 问题

微信进程可能保留标题同为“微信”的极小辅助窗口。共享定位器只按标题计数，会把 42×40 的残留窗口与正常主窗口一起判为重复主窗口，导致生产预检误报 `wechat-main-window-count-not-one`。

## 方案

1. 主窗口候选必须同时满足标题为“微信”、宽度至少 700、高度至少 500。
2. 过滤后仍必须恰好一个候选；两个正常尺寸主窗口继续失败关闭。
3. 窗口激活、边界读取、辅助功能树、专用技能输入模块、复制回读、输入框聚焦和发送按钮定位使用相同判定，避免各阶段标准不一致。
4. 不自动关闭任何窗口，不改变群定位、输入、发送和证据规则。

## 验收

- 当前一个正常主窗口加一个 42×40 残留窗口时预检通过。
- 两个正常尺寸主窗口时仍返回 `wechat-main-window-count-not-one`。
- 共享技能、商户流程回归全部通过，真实生产发送仍需完成非空验收后才能封板。
