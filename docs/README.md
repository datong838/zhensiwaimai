## 归档规则（新文档怎么放）

1. 写的是**系统级机制/底座/组织设计** → `architecture/`，命名建议 `YYYYMMDD-主题方案.md`
2. 单个流/页面/环节的**方案、复盘、实施、待授权** → `solutions/`
3. 手册、清单、对照表等**长期被值班/执行消费**的 → `operations/`
4. 移动已有文档时：**必须**全仓 grep 旧路径引用（`docs/<名>` 形式）并同步更新；**封印面文件（skills/ 下被 dependencies.json / executor-lock.json 钉 SHA 的）一个字节都不能动**——2026-10-06 实测：改 `dependency_maintenance.py` 一行注释即 `executor-lock-digest-mismatch`。
5. `work/` 下的历史台账是当时快照，里面的旧路径引用**不改**（保留历史原貌）。
