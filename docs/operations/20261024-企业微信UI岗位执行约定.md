# 企业微信UI执行岗位

## 现行规则（2026-10-25，覆盖早期试验约定）

用户授权的链路为：原工作流/车间主任提交原队列任务 → UI岗位执行 → 原流程核验收据。群名、载荷、事件、防重账本均来自原流程，监理不临时代发。

### 唯一实操实现

只用macOS系统原生System Events公开UI scripting，固定企业微信bundle `com.tencent.WeWorkMac`与真实“企业微信”主窗。实现位于`skills/wechat-messaging/scripts/native_ui_tree.py`、同目录`native_ui_tree.jxa`与`native_ui_post.py`。不依赖特定模型产品、界面会话句柄或屏幕共享工具；禁止CUA应用控制、屏幕捕获、截图/OCR坐标点击、Quartz/CGEvent、AXSetValue及隐藏发送接口。

诊断/探测只能读取真实UI树属性，不输入、不按键、不点击、不抢焦点、不打开右键菜单；不得发测试文字。精确控件路径与角色/描述缓存在`config/native-ui-selectors.json`；失配只读相关浅层子树，唯一匹配且全部锚验证后更新缓存，禁止反复全树扫描。

### 原任务与防重复

任务来自`skills/wechat-messaging/.runtime/ui-post-queue/<uuid>/task.json`。校验原taskId/binding、workflowId、完整群名、载荷SHA和创建者真实进程身份；使用原claim和原send-intent。任何已有发送意图或unknown不得自行重发。零发送恢复须有独立实际证据并归档原记录，不能仅据超时或调用失败认定没发。

当前新任务使用owner-process生命周期：创建者及父进程真实身份有效时继续完成，不以wall-clock剩余时间中断业务。旧任务历史deadline/协议偏差仍保留，不能补造合规记录或借旧owner继续操作。此规则不撤销原防重或真实群/载荷核对。

### 精确导航与一次发送

预检只做一次必要核对；完整群名已正确且输入框空则直接使用。需要切群时，使用真实“编辑→搜索”菜单已验证的Command+F，精确搜索框可见粘贴完整群名，读取实际值，Return进入后核对完整会话标题。诊断不能借用这套业务导航。

正式业务操作才短暂激活企业微信并确认真实焦点。保留用户平铺窗口布局，不最大化或挪动窗口。不能覆盖用户或未知草稿；文字使用系统剪贴板可见粘贴，读取实际草稿全文与源SHA一致后只按一次Return，多行不得拆成多条。

Excel经真实“选取文件”选择器定位冻结原路径，完整文件名/大小/源SHA绑定；“使用原文件”可能直接发送，事前必须有意图，点击一次后只读核验，不追加Return。图片经真实“选取图片”入口，绑定原图片路径与SHA，作为inline图片发送，不发PNG文件卡。

### 回执

文字：新增消息的实际全文SHA、完整目标群及空输入框，两次独立观察一致。文件：新增实际文件卡完整文件名、显示大小及空输入框，两次观察一致；源SHA不冒充聊天附件字节回读。图片：必须有实际inline内容或足够的真实图片结构证据，只有新增空白cell/时间不算verified。缺少图片证据返回unknown，不为补证重发。

只读readback不创建发送意图，sendAttempts=0。当前原生CLI尚未支持通用历史readback，不能调用send函数代替。原生文字/文件正常业务已多次verified，图片存在UI树不暴露内容的限制，不能笼统宣称所有图片端到端已验收。

### 岗位接通与运行边界

允许范围由原`wecom_ui_queue.enabled`与`registered_ui_routes`读取真实请求判定，不能凭本文扩大。包括已登记文字/图片/Excel工作流、商家通知、客服附件与当日最终台账；不发送项不生成外发任务。运营群为“上海臻肆外卖运营-盯个盯-饭敢当 💰发财精英荟💰”，新商家仅“电销+直播攻坚组”。

当前由UI岗位消费原队列并调用原生CLI；自动派发尚未启用，不能宣称无人值守全自动。原生日常操作不需要屏幕共享会话；系统辅助功能权限缺失时报告具体外部条件，保留任务，不改用共享或隐藏接口。

## 历史事故事实（不能复用旧操作路径）

早期CUA应用接口曾启用系统“当前正在共享”提示，用户手工停止；该应用控制路径已禁用。紫色图标不能单独证明平台风控。截图坐标点击曾未切群并误开独立运营群窗口，禁止再用。

早期System Events keyDown/keyUp传入字面control产生输入法组合残留。该探测已删除，入口在任何UI调用前拒绝modifier点击及任意按键字符串；后端不存在keyDown/keyUp。未发送该组合文本，已取消组合并核对空框。后续只读属性探测，不再试按控制键。

旧deadline造成附件任务/晚回执停止的记录保持原样；新owner-process路径不沿用“剩余不足60秒停止”规则。控制方法、焦点与UI验证以本页现行规则及对应源码为准。
