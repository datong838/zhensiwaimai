# 监理新对话完整交接模板

1. **交接身份**：交接时间/AsiaShanghai日期、运行日/数据日/明日预检日、源/目标threadId、仓库/分支/远端HEAD、执行所有权阶段。
2. **最新用户约束**：当日流数量及生效日期、用户业务验收、台账发送授权/hold、另一机器三流归属、消息/浏览器/防重边界；明确覆盖哪些旧规则。
3. **完整Goal**：原objective逐字全文、真实status、get时间及来源；已完成/未完成逐项证据，不能只传浓缩摘要或改写成功条件。
4. **当日业务交付**：全部当日台账行、班次/合并别名、实际执行与送达/人工验收凭据、真实异常；技术unknown原件保留、不能重发；当日最终台账文件SHA和原送达收据。
5. **遗留清单**：每项原问题、证据、根因/未知、影响/优先级、变更文件、方案、测试/原门、待真实验收、恢复与禁止事项、下一行动。
6. **明日预检**：全部当日口径27流（后续动态）的逐流检查结果/证据、业务日期、依赖和release、数据/名单/完整来源、未来数据到点复核；另一机器三流只记已提供摘要和归属。
7. **代码交付**：已部署/候选/未部署分别列，源码和资料commit/push验证、未提交文件、测试范围/结果、失败及修复、回滚原件与指令边界。
8. **数据与状态**：本机权威路径、运行资料/原队列/账本/防重/游标、当日证据/原报告/模板、共享browser依赖、保留/禁止改动原件；不含凭据或会话数据。
9. **运行环境**：launchctl、daemon/control、四岗端口/业务域、原UI岗、活进程启动身份/锁归属/在途任务；快照需新聊天重新核实，不当作永久健康或抢锁许可。
10. **全部定时任务**：id/名称/时区/规则/启停/通知/原target、目标target、嵌入threadId替换、迁移前后回读；当前02/06/08/20/22，共5项但每日重新完整发现。
11. **Goal与任务迁移收据**：新聊天只读核收、源Goal官方clear/null、新Goal完整objective/active、所有定时归属核验；失败与恢复步骤，不伪complete，不双执行。
12. **立即接续与截止**：新聊天第一步及优先级、下一真实验收时间、22维护、06收口/08启动、真实外部条件与待到点事项；继续工作不等待用户再次说开始。

附：所有证据索引、latest入口及本次完整机器可读交接JSON。新聊天必须能不翻完整旧聊天而继续全部工作。
