# 原生UI测试群实操验收

## 范围

仅“临时测试群请忽略 💰发财精英荟💰”，合成文字、Excel、图片，唯一标识NATIVE-20261025-A01/A02/A03/A04。原WeComAdapter→原executor→原队列→System Events执行器，无共享、截图坐标或隐藏发送。源图片为工作簿合成渲染42KB，不含客户数据；原业务群无测试外发。

## 结果与修复

- A01从用户台前调度左侧收起的状态开始，搜群6.5秒，文字8.3秒verified，图片单次提交后AX未暴露内容，仍继续Excel；文件选择器准备附件草稿、未出现预览，旧代码误报unknown。保留旧记录，已知测试附件草稿清理留证，不重发该项。
- 文件分支补齐实际附件草稿、确认预览及已新增文件卡三种状态。A02独立合成Excel实际verified，21.6秒；同事件再次调用2毫秒，零UI操作/零发送。
- A03首轮用户打字与调前操作冲突，多出z前缀，被全文校验挡住，blocked0；用户确认原因并授权清理重跑。补上取得焦点后、粘贴前群和空框复核。该校验减少错误内容发送风险，不等于消除了抢焦点干扰。
- A03后续图片选择器在即时读取时未就绪，稍后只读出现真实“选取图片”控件；补齐真实选择框局部状态等待及语义定位。未把异步就绪误判成风控，不使用坐标补点。
- A03沿同一事件续跑：已verified文字未重发；图片14.4秒单次提交后unknown，Excel16.1秒verified，executionComplete=true、verificationPending=[image]。该次续跑32秒，不能当作从搜群开始的整批无故障耗时。
- 用户明确确认A03“图片正常显示”，作为独立用户验收；原unknown不改为自动verified。整批再调用1毫秒、零preflight/send阶段、零重发。

- A04完整单次调用：Excel→图片→文字共40.159秒，单次预检0.802秒，分别16.723/13.631/8.997秒。Excel、文字verified，图片unknown且sendAttempts=1，executionComplete=true。图片未知没有阻断后续文字；A03用户确认仅属于A03，不挪用到A04。

## 实际限制

原子实操含义是原流程的一次完整调用内连续导航、准备、发送及核验，无模型往返，不是操作系统不可中断事务。实际媒体仍约14–22秒，未达到每种10秒以内；不能把提效写成已满足该速度目标。

UI树可在后台读取，但现有键盘粘贴/Return依赖真实前台焦点；用户同时打字可能冲突。不承诺全后台或零干扰，不擅自改用注入/AXValue写入。图片AX语义仍可能不暴露，采用未知保留、后续继续、异步只读核对，不以询问人工作为执行前置。
