# 归仓全量提交范围

用户明确要求本次代码、资料、脚本和新增文件一起提交。统一纳入当前仓库所有Git可版本化改动，包括既有修改、删除、新增、方案、测试、兼容脚本及部署材料；仓内所需vendor库一并提交，不能因node_modules默认忽略而漏交。

保持原业务状态边界：登录资料、凭据、浏览器profile、持续变化的账本/游标、运行历史和缓存继续按原忽略规则在本机保留，不为提交改写业务数据。历史归档中的已识别源码、规则与说明纳入；凭据连接配置、旧运行日志、嵌套Git元数据不作为源码提交。归仓SHA与生产验收材料在既有runtime/state本地证据根保留，静态方案与验收清单入仓。

只做本地Git提交，不推送远端。提交前检查全部改动、空白错误及高置信敏感信息，提交后核对commit与剩余未提交项。不停止主任或浏览器，不改变业务排班。
