## 根因（2026-09-30 现场取证，已订正）
1. **渠道 tab 未删除，是移进侧边栏且会随侧边栏收起而消失**：
   - 金鲨「实时数据」改版后，渠道切换器 `.cutli`（美团/淘宝/京东）仍在 DOM，但被收进侧边栏容器（`sidebar-container > cut`）。
   - 当浏览器窗口宽度 **< 992px** 时，应用切到移动抽屉模式，侧边栏默认收起，`.cutli` 整体不在 DOM → `switchChannel` 的 `.cutli` 唯一性闸门直接 `channel-not-unique` / 缺失。实测窗口 967px 即触发。
   - 修复：`collector.mjs` 新增 `ensureChannelTabsVisible(page)`——仅在 `.cutli` 缺失时点击**汉堡按钮**。落点必须是 `svg.hamburger`（外层 `hamburger-container` 为 0 尺寸容器，点无效）；不绑定父级（`.navbar` 在两种布局间有无切换），按全局唯一匹配。
2. **暂停营业店铺不渲染开业天数**：
   - 淘宝最后一页 `渔味妙酸菜鱼·肥肠鱼·烤鱼(浦东大道店)` 为暂停营业，金鲨不渲染「开业天数」→ 该行 days 为空。旧 `unresolved` 把任何空 days 行都计入「待核对」，非空即 `run()` 阻断发送、永不送达。
   - 修复：`readRows` 增加 `suspended` 标记（`!days && avatar.includes('暂停营业')`）；`unresolved` 过滤排除 suspended；`page-incomplete` 闸门下 suspended 有店名仍算完整；suspended 单独记入报告「已排除」节，透明展示。
