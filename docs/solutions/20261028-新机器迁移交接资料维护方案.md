## 修改范围

1. 新增机器可读的当前迁移交接 JSON，记录当前代码版本、已完成事项、未完成事项、旧机运行快照、迁移边界、启动顺序和验收条件。

## 迁移控制顺序

1. 新机器只读拉取并核对 `origin/main`，不得从旧机复制 Cookie、localStorage、钥匙串、浏览器 profile 或其他会话凭据。
2. 新机器安装解释器、浏览器岗位、企业微信 UI 能力和调度依赖；旧机继续保持唯一生产所有者。
3. 新机器完成离线检查与合成载荷测试，但不得使用生产事件、防重键或目标群冒充正式验收。
4. 到正式切换窗口时，先确认无在途任务并停止旧机调度入口，再迁移 Goal/五项定时归属；任何时刻只允许一个生产控制通道。
5. 新机器重新核验登录、业务正文、四岗位、原队列/账本身份和正常班次真实回执后，才可记迁移验收完成。
