## 风险与限制
UI树浮层缺失时不能回退坐标；使用真实列表项或焦点明确的键盘导航。系统UI脚本权限失败属于外部条件，保留原任务，不开启共享。单纯UI树可读不等于完整交付通过，必须实测原任务。
