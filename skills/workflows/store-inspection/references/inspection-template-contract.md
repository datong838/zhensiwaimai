# 门店自检模板合同

## 唯一模板

- 文件：`runtime/门店自检表(框架+模板).xlsx`
- SHA-256：`768f7d095656d569ed517492b9cbd740815428d934fbf8c40cca908d59daa271`
- 工作表：`Sheet1`
- 范围：`A1:C45`
- 表头：`项目｜注意事项｜具体方案`
- 明细：第 2–45 行，共 44 条检查点；A 列空白表示继续隶属于上一个非空项目，共 20 个项目。

每次执行前校验文件哈希、工作表、表头和行数。任一不符即停止，不能使用旧输出结构或自行推断新模板。

10. 收藏及老客户

19. 推广
20. 门店宣传

## 行级输出

模板每个明细行都必须输出，原顺序不变：

- A 列：保留模板值，包括用于表示同一项目续行的空白单元格。
- B 列：`检查点：<模板原注意事项>\n巡店发现：<本店已验证问题或已符合>`。截图仅用于过程复核，未随结果表交付时不得展示文件名或“证据：”行。
- C 列：仅对已有巡店发现填写针对该店的可执行方案。
- 当前消费者端或后台没有取得该字段时，B 列中的“巡店发现”和 C 列均留空；不得填写“未核验”“UNKNOWN”或推测数字。两者只能同时为空。

禁止只输出有问题的行。禁止用评分、月售等少数消费者端指标代替 44 条模板检查点。

## 证据映射

- 搜索结果：店名、评分、销量、起送价、配送费、距离/时效、预订提示。
- 商品首页和下翻：Logo、关键字、分类、商品名称/描述/配图、价格带、引流款/爆款、活动。
- 评价和差评：评分、差评主题、回复情况、包装/分量/口味问题。
- 商家页：地址、营业时间、配送时间、品牌/证照及服务标签。
- 消费者端不可见：老客/复购、后台自动回复、补贴承担、推广余额、平台招商报名、真实出餐时间、配送范围面积等，对应结果字段留空。

## 合规覆盖

模板历史文本含“好评返现、刷单、霸王餐”。结果中不得把这些行为作为方案；只能使用真实顾客回访、合规评价邀请、差评闭环、出品与包装整改、以及平台允许的活动。
