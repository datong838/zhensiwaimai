## 标准流程

1. 运行三个执行器离线自测和只读预检。
2. 运行下载执行器；两个平台必须各得到一个业务日期正确、结构有效且包含 `店铺ID` 的新 Excel。
3. 运行制表执行器；按 VLOOKUP 首条语义审计客户表重复键，补齐两列，按营收降序和模板列序生成，重算条件格式，检查关键范围、扫描公式错误并渲染所有工作表。
4. 在发送前输出两个成品的绝对路径、大小和 SHA-256 自查。
5. 运行微信发送执行器；只允许普通微信「臻肆测试群」与收据中的两个文件。逐文件单击一次发送，看到完整文件名的新气泡后才进入下一文件。
6. 最后复核两个文件气泡、发送次数和收据哈希。

文件发送位置固定走「手机文件 → 选取 → 系统文件选择器 → Download/zhensi_reports」，不是默认的「聊天」历史文件列表。具体 UI 树定位和动画稳定要求见工作流合同。
