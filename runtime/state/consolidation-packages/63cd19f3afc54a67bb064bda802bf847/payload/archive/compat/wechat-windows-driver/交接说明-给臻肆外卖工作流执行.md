## 你现在能干什么

通过 Windows 侧微信驱动服务，用微信把**文字、本地文件（自动识别图片/文件）、批量任务**发到指定群或联系人。适合：日报推送到群、报告/报表投递、运营通知。

## 一键用法（复制即用）

```bash
cd /Users/ddt/work/projects/ai_agent/wechat-windows-driver
PY=/Users/ddt/.workbuddy/binaries/python/envs/default/bin/python

# 发文字（群名前缀匹配，不用写全"已置顶"后缀）
$PY wxsend.py "臻肆测试群" "今日外卖运营日报已生成"

# 发本地文件（自动上传+自动识别：png/jpg 走图片，xlsx/pdf 走文件卡片）
$PY wxsend.py --file "上海臻肆外卖运营-盯个盯-饭敢当" /path/to/日报.xlsx

# 探活（ready:true 才可发）
$PY wxsend.py --status

# 列会话真实群名（发之前核对）
$PY wxsend.py --sessions
```

- `wxsend.py` **自动读配置**（IP/TOKEN 从 `接入包/连接信息.txt` 解析），不需要设环境变量
- 内置 3 次重试；内置 3 次重试兜「打开会话失败」偶发问题
- 需要更复杂能力（批量多群、读当前会话消息、列服务端目录）用官方 `client.py` 的 `WeChat` 类，完整 API 见同目录 `USAGE.md`

## 使用纪律（务必遵守）

1. **发出去撤不回**：首次对新群发送，先发「文件传输助手」验证；批量先 `dry_run`
2. **测试用「臻肆测试群」**，正式运营消息再发运营群；别拿客户群做试验
3. **服务端会偶发崩溃**（尤其发文件后）：发送失败先 `--status` 探活；挂了就等 1-2 分钟重试或反馈 Windows 侧，**不要循环轰炸**
4. 服务端**单线程串行**：文字 3-6 秒/条、文件 8-20 秒/条，批量任务别并发
5. 只能发 + 读当前会话；**没有收消息推送能力**，别设计依赖收消息的流程
6. TOKEN 在 `接入包/连接信息.txt`，不要写进代码/日志/外发
