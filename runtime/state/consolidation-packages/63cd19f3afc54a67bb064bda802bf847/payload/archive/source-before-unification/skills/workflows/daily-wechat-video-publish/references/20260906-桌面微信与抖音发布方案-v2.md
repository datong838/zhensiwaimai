# 微信群视频 → 抖音发布 v2（Mac 桌面微信）

## 变更摘要（相对 v1 手机方案）

| 项 | v1 | v2 |
|---|---|---|
| 微信控制 | 手机 ADB/uiautomator2 | **Mac 桌面微信**（`wechat-desktop-control`：CGEvent + OCR） |
| 候选扫描 | 手机控件树 | 桌面聊天区 OCR + 滚动 |
| 下载 | 手机保存/缓存 | 原生 `[视频]` 右键另存为 / 缓存轮询；**视频号卡片不算原视频** |
| 抖音 | Chrome CDP 9222 + Playwright | 不变 |
| 批次目录 | `runs/<run_id>/` | 不变 |

## 输入合同

- **群名**：逐字匹配，如 `红太阳鱼杂王蜀川湘菜店抖音发视频`
- **发送人**：微信昵称，如 `略略略`
- **起始时间**：Asia/Shanghai，如 `昨天 19:00` → ISO `2026-09-05T19:00:00+08:00`
- **映射表**：`/Users/ddt/work/臻肆/视频/微信群-店铺名-店铺地址.xlsx`
- **批次根目录**：`/Users/ddt/work/臻肆/视频/runs/<run_id>/`
- **历史索引**：`/Users/ddt/work/臻肆/视频/processed_index.json`（跨轮去重，不与本轮文件混放）

## 作品描述规则

```
{封面 OCR 文案}，{约10字广告词}｜{店铺名}｜地址：{详细地址}
```

示例：

```
一锅端起全是料，这鱼杂的含金量谁懂啊，😋鱼杂王中王，舌尖上的鲜，从这锅鱼杂开始｜红太阳鱼杂王·蜀湘川菜(杨浦保利店)｜地址：上海市辽阳路195号-24...
```

抖音发布页**只填**：作品描述 + 地理位置（店铺地址）。其余默认。

## 状态机

`candidate → download_pending → downloaded → prepared → publish_pending → submitted → verified`

## CLI 入口（workflow_executor.py）

```bash
# 1. 初始化批次
python3 scripts/workflow_executor.py \
  --group '红太阳鱼杂王蜀川湘菜店抖音发视频' \
  --sender '略略略' \
  --cutoff '2026-09-05T19:00:00+08:00' \
  init

# 2. 扫描群聊（桌面微信 OCR）
python3 scripts/workflow_executor.py --run-id <run_id> scan

# 3. 下载原视频到 runs/<run_id>/videos/
python3 scripts/workflow_executor.py --run-id <run_id> download

# 4. 生成描述与发布计划
python3 scripts/workflow_executor.py --run-id <run_id> prepare

# 5. 发布到抖音（需 --confirm-publish）
NODE=~/.nvm/versions/node/v20.20.2/bin/node \
  python3 scripts/workflow_executor.py --run-id <run_id> publish --confirm-publish

# 评论回复（单条授权，与发布分离）
NODE=~/.nvm/versions/node/v20.20.2/bin/node \
  python3 scripts/workflow_executor.py --run-id <run_id> reply-comment \
  --work-id <作品> --comment-id <评论> --text '回复内容' --confirm-reply
```

## 去重键

`sha256(file)` 优先；否则 `group|sender|messageTime|coverText|duration` 复合键。已在 `processed_index.json` 中 `verified/submitted` 的跳过。

## 抖音 CDP

- 复用用户已登录 Chrome，`http://127.0.0.1:9222`
- 上传页：`https://creator.douyin.com/creator-micro/content/upload`
- 管理页回读：`/creator-micro/content/manage`
- 须 Chrome 以 `--remote-debugging-port=9222` 启动；探测失败则停止，不代登录

## 评论回复

遵循 `sc-server/vedio/douyin`：作品 → 精确评论 → 展示拟回复 → 单条 `--confirm-reply` 发送 → 回读。
