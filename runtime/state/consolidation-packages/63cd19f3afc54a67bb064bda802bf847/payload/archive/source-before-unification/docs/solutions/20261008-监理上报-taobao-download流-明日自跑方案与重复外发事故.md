- **★★★ 重跑带对外发送的生产流 = 重复外发。** 跑之前必须先看该流末端有没有发送步骤、marker 是什么状态。`attempted`（已发出无收据）不是"没发过"。

- **★ 少传图**：群内证据图能合并就合并、能不发就不发，重复图是噪音也是事故。
