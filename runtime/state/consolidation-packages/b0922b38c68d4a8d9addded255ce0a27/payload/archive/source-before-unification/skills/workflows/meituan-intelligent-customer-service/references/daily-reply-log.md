# 当日客户回复记录

## 文件与粒度

- 过程记录使用一份临时 Markdown 台账，文件名为 `待整理客户回复-YYYY-MM-DD.md`；每个自然日另有一份 Excel，文件名为 `美团客户回复记录-YYYY-MM-DD.xlsx`。
- 同一天只追加，不另建重复文件。
- 只记录已实际发送、并且已在美团会话中回显的消息。
- 每条回显后立即写入临时 Markdown 台账；每日 20:00 后统一核对并整理进 Excel。Excel 异常不得造成临时台账遗漏。当日没有已回显的客户回复时，Excel 仍保留表头并明确记录“0 条已核验回复”，不得复制前一日记录。

## 必填列

1. 日期
2. 发送时间
3. 脱敏会话标识
4. 门店
5. 客户问题摘要
6. 实际回复
7. 平台核验状态
8. 备注

## 隐私与状态约束

- 不记录顾客地址、完整订单号、支付信息、联系方式或完整聊天历史。
- 候选、草稿、发送失败和状态不明的消息不可标为“已发送”。
- 发送后先读取会话回显，再写入临时台账；回显未确认时仅记录为“待核验”，不得重发。
