# 美团客服工作台 UI 树读取路径

## 商家首页到客服工作台

1. 先确认 `127.0.0.1:9233` 的隔离端点可达，再在该端点中只锁定 `https://waimaie.meituan.com/` 的唯一商家首页。不得使用日常 Chrome、共享浏览器或其他浏览器端点。
2. 右下角“消费者问题消息”入口在 iframe 内。先验证 iframe 与可点击入口唯一，再点击一次。
3. 点击会新增 `https://waimaie.meituan.com/imworkbench/` 工作台页面；不要假定首页标签页已经切换。
4. 只锁定这个 `imworkbench` 前缀页面，不枚举或报告其他标签。

## 会话区

- 页面身份：标题区“商家总客服小美”。
- 路径：点击“全部顾客消息”，再点击“未回复”。
- 强制门禁：所有列表读取放在 `runWithUnansweredQueue(driver, scan)` 回调中；它依次选择两项并断言主标签 `.tab-item.active` 为“全部顾客消息”、筛选项活动态为“未回复”。筛选项定位限定为 `[class*=historySessionFilter] > div` 中唯一精确文本“未回复”；若已活动则保留、不再点击。门禁失败时扫描回调不会执行；不得以“超时未回复”卡片字样、当前残留页签或上一轮状态代替。
- 会话卡片：`[class*=sessionListItemContainer]`。
- 列表容器：`[class*=sessionListPanel]` 内的可滚动列表；以该容器为目标做增量滚动，不滚动客户聊天正文。
- 每个可见卡片只读取最小字段：脱敏标题、时间、最新预览、自动/机器人标记、紧急标签与未读数。
- 仅在卡片初筛通过后打开单个会话，读取必要的尾部消息与角色来确认“最后诉求”和“店主人工回复”。先排除加微信、联系方式、纯数字、乱码、广告和其他非餐饮订单信息；这些内容不进入建议流程。打开会话可能改变未读状态，必须在收据中说明。

## 快捷回复区

1. 右侧点击“快捷回复”，再点“个人话术”。
2. 话术滚动容器：`div.group-list`。
3. 完整文本：`span.reply-text`，不要使用视觉省略内容或 OCR。
4. 素材状态：同一 `reply-container` 内的 `span.reply-label`。
5. 通过设置 `.group-list` 的滚动位置逐段读取，基于“分组名 + 完整文本”去重；读取后可恢复原滚动位置。

## 禁止动作

- 不读 Cookie、Local Storage、密码、网络认证头或浏览器历史；
- 不点击纸飞机、发送、退款、补偿、改餐、订单详情、客户地址或联系信息；
- 不用坐标猜测会话、页面或话术；
- 不用自动回复、未读数字或 UI 标签推断人工已回复/未回复。
