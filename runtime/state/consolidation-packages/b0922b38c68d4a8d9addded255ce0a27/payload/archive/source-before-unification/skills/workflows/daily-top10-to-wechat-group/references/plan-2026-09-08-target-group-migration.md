# 目标群迁移方案（2026-09-08）

## 目标

将本流程唯一目标群从历史测试群迁移为精确群名 `FEIBING NEO AI数字员工`，保持主微信、单张昨日 Top10 原图、单次发送及发送后复验合同不变。

## 最小变更

1. 更新运行期唯一群名与群名绑定的站立授权标识。
2. 发送账本按目标群建立独立命名空间，保留旧群历史账本，禁止删除或复用旧发送记录。
3. 群名匹配统一消除空白，并兼容 OCR 将 `AI数字员工` 识别为 `Al数字员工` 或 `AL数字员工`；运行合同和发送收据始终保存标准名称 `FEIBING NEO AI数字员工`。人数、图标噪声仍可忽略，附加中文名称、紧跟数字或相似群仍拒绝。
4. 更新当前操作文档和测试样例；历史稳定化方案保留原始记录，不改写历史事实。
5. 物理手机已连接但正常息屏时，执行器只发送系统唤醒键并短轮询屏幕与分辨率；不尝试解锁、不修改常亮设置。桌面完成交接手机前再执行一次相同归一化。
6. 当前页未直接暴露「门店分析」子菜单时，必须先按当前元素几何悬停唯一「数据中心」菜单项；短轮询仍未出现时才允许一次真实单击补偿。唯一「门店分析」链接出现后立即点击，禁止无动作等待或重复点击。
7. Chrome 网页中的 `AXMenuItem` 与 `AXLink` 不使用可能仅取得焦点的 `AXPress`；必须根据当前 AX 元素几何计算中心并发出真实鼠标移动或单击。其他支持 `AXPress` 的表单控件保持原逻辑。
8. 悬停浮层在画面可见但 AX 不暴露「门店分析」时，原生桥接器截取当前 Chrome 原像素窗口，用本地 OCR 在左侧菜单区域唯一定位完整文字「门店分析」，将截图像素中心换算为当前屏幕坐标并单击一次。候选不唯一或置信度不足时停止，禁止固定坐标。
9. 微信搜索结果按当前可见分区标题确定边界：接受「最常使用」或「群聊」分区内的唯一精确群名，以下一个「群聊 / 创建新的群聊 / 聊天记录 / 搜索网络结果」标题为下边界；不再强制要求页面必须出现「搜索网络结果」。
10. 若经明确授权从已成功桌面收据续跑手机，续跑账本一旦创建，同日期同目标群的默认发送也必须视为已尝试；只有另一个明确的重复授权 UUID 才能再建立一次独立尝试，结果未知仍禁止补发。

## 安全边界

- 只允许主微信、唯一群 `FEIBING NEO AI数字员工`、一张本流程自检通过的昨日 Top10 PNG。
- 搜索结果必须唯一，进群后必须再次核对顶部群名。
- 群名不一致、候选不唯一、发送结果未知或复验失败时立即停止，不自动重发。
- 不关闭、不修改用户的其他 Chrome 标签；存在多个匹配标签时，先接受唯一一个“其所在窗口当前活动”的匹配标签；若多个 Chrome 窗口都各自活动在匹配标签，则只接受 Chrome 最前窗口中的活动匹配标签。仍不能唯一确定时，执行前失败关闭。

## 验收

- 手机执行器自测与安全测试全部通过。
- 旧授权标识不能触发发送；新授权标识与新群名同时满足才可执行。
- 正例覆盖空白、人数和 `Al` OCR；反例覆盖临时群、相似群、附加中文和紧跟数字。
- 完整实操以桌面收据、手机收据、一次发送尝试和群内大图复验为准。

> 2026-09-10 起浏览器段已迁移到后台专用 Profile；原文第 6–8 项和“其他 Chrome 标签”属于历史前台适配，不再是当前执行分支。目标群、授权和发送账本规则保持有效。
