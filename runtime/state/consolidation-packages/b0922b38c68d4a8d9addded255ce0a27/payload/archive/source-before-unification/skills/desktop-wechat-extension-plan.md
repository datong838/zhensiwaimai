# 普通微信桌面通道扩展方案（2026-09-09）

## 目标

为当前依赖手机普通微信的业务技能增加 macOS 桌面微信执行通道，同时完整保留既有手机实现、参数默认值、授权、幂等、游标和失败关闭规则。

## 适用范围

- `daily-agent-new-merchants-to-wechat`：逐条发送四行文字。
- `daily-top10-to-wechat-group`：发送一张原始 Top10 图片。
- `daily-taobao-download-to-jinsha`：发送数据上传和评价上传两张完成截图。
- `daily-jinsha-reports-to-business-wechat`：发送两份日报 XLSX。

`daily-wechat-video-publish` 已使用桌面企业微信，不属于本次普通微信扩展；`store-inspection` 的手机阶段用于外卖 App 巡店，不可由桌面微信替代。

## 技术方案

1. 在 `wechat-desktop-control` 增加确定性发送命令，支持 `text`、`image`、`file` 三类载荷。
2. 发送器只连接已登录并已有可见窗口的 WeChat，不启动登录、不读取凭据。
3. 每次执行先精确打开唯一完整群名并复核标题；载荷在输入前计算 SHA-256。
4. 文字通过剪贴板粘贴；图片和文件通过 macOS 文件剪贴板粘贴。发送前保存截图并创建 attempted 收据，只触发一次发送键。
5. 发送后要求群标题仍一致、输入区恢复为空，并通过新出站气泡的类型、文件名或文字摘要进行两帧稳定复核。结果不确定时保留 attempted，禁止再次发送。
6. 业务执行器新增显式通道参数。默认 `mobile`，显式 `desktop` 才调用桌面发送器；`noop` 不连接任何微信。
7. 手机与桌面共用业务级去重键，通道仅写入审计字段，不能借切换通道绕过去重或 attempted 锁。

## 最小变更与兼容性

- 不删除、不重写手机执行器。
- 不改变现有群名、消息模板、业务文件、生产/测试游标及账本位置。
- 桌面执行器是新增依赖，桌面不可用时失败关闭，不自动回退手机；反向亦然。
- 历史命令未传通道参数时行为与修改前一致。

## 验证计划

1. 共享发送器离线测试：群名精确匹配、载荷哈希、attempted 防重、未知结果禁止重发、文件类型约束。
2. 四个业务入口参数和路由测试：默认手机、显式桌面、`noop` 不触发微信。
3. `wechat-desktop-control` 技能结构校验。
4. 已登录桌面微信只读 `probe`；不发送测试消息。

## 风险与停止规则

- 微信版本或窗口布局变化导致标题、输入框或气泡无法唯一识别：停止，不盲点。
- 发送动作已触发但新气泡无法确认：标记 `unknown`，禁止手机或桌面补发。
- 桌面微信被遮挡或焦点丢失：发送前允许一次有界恢复；发送后只读复核，不再次触发发送。
