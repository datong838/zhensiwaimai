## 1. 需求回顾

金鲨 SaaS 负反馈列表页，对美团、淘宝近 7 日数据发起「立即申诉」，明细入 md，完成后双平台

## 2. 关键决策：两平台结构不同 → 分模式 + 双 Excel

实机只读勘察（diag_taobao3/diag_taobao4 + verify_collect）证明：

- **美团**有完整「申诉类型 + 申诉状态」双 tab，未申诉(9) 条目带按钮，可直接定位。
- **淘宝****没有**这两个 tab，取而代之是 `.nav_li` 分类筛选（全部/食品安全负反馈率/服务负反馈率）；
  默认激活「食品安全负反馈率」，**全部(139)** 视图下所有卡片都带「立即申诉」，页面**不呈现申诉状态**。

据此（大同 2026-10-06 拍板）：
- 淘宝只用「全部」分类视图作为申诉源，不再去找不存在的「申诉类型/未申诉」。
- **美团、淘宝各出一份独立 Excel**，因结构不同分而治之，降低耦合与口径错乱风险。
- 淘宝不重复申诉**唯一护栏** = 跨日本地账本（`existingStatusAnyDate`），因为页面无法判断已申诉。
