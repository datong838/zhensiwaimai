## 范围与规则
用户要求故障出现后立即调查，业务优先。不通过反复点击替代诊断。只读系统身份及真实UI树、可见UI操作；不改系统参数、不注入、不关闭既有主窗口、不变更发送账本。先识别应用/窗口/控件归属及真实点击目标，再最小恢复。

## 已核验事实
- 13点商家原run130926收集到1名新增，卡于预检600秒后失败，发送0；这证明残留内部倒计时，不能证明账号风控。
- 用户截图显示电销群搜索结果存在，右侧仍运营群；搜索成功与进入会话必须区分。
- UI岗位报告坐标点击未切群、双击误开运营群独立窗口，说明截图坐标与真实命中至少一次不一致；已关闭该新开独立窗口，停止坐标重试。

## 正在取证

## 修复判据
