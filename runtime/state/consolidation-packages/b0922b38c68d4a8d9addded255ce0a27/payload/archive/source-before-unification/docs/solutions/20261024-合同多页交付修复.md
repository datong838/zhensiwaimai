# 合同多页交付修复

原节点构造全部截图items，但仅send_one(items[0])，然后把整个事件标verified，可能遗漏后续页。

最小方案：原deliver内顺序逐页发送image，每页独立transport目录，页结果写回原事件的pageReceipts。任何非verified立即停止，整个事件保留unknown，后续调用沿原规则不重发。异常保留已完成页的结果与未知次数；仅全部页verified时整体verified。发送次数总和存在未知则整体为null。保留原day/event/锁/授权、旧verified与unknown不重写、不迁移。先完成原节点离线验证，再按下文接通常规UI路由。

涉及：skills/workflows/contract-termination-applications-screenshot/scripts/contract_termination_workflow.py；新增tests/test_delivery.py。

测试：两页全部成功后才整体成功；第二页unknown停止第三页且再次调用不重发；第二页异常保留第一页证据；单页成功兼容。使用临时本地文件、FakeAdapter，不连接业务浏览器、不操作企微、不触发补发。今天撤回的旧事件仍未完成。
