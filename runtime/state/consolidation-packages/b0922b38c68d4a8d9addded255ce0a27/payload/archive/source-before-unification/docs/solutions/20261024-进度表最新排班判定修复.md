# 进度表最新排班判定修复

问题：固定多档流程的进度表只检查当日最早时刻，旧档成功会掩盖18:30收口失败。

最小方案：仅修改 runtime/daily_progress.py，存在 schedule_times 时直接复用 fixed_schedule.gate 的当前最新到点边界；其他流程维持原判定。未到首档不算完成，旧档成功不顶最新档。保留全部原运行记录及成功时间，不触发补跑、不改账本。

验证：隔离临时目录模拟13:10成功、15:00到点、18:30失败以及18:31成功；验证普通单档原行为。新测试 runtime/test_daily_progress_slots.py。此修复只改善真实状态报告，不等于业务送达完成。
