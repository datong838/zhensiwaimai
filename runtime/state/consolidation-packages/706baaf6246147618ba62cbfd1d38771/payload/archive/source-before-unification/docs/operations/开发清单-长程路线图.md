## 0. 维护铁律（最高优先级，违反即回退）

1. **备份优先**：所有改动只在 `zhensi_waimai_back/` 上进行；原 `zhensi_waimai` 只读参照、不再改。
2. **安全门零改动**：各 skill 内的 `EXTERNAL_EFFECT fail-closed` / 防重账本(`atomic_json`) / 逐字授权 / `ActionResult` 收据 / `policy sha256 fail-closed` / `UNSEALED_ACCEPTANCE` 一律不碰。
3. **薄包裹层**：统一调度层只按 manifest 以命令行方式包裹各 skill **现有入口**，零改 skill 内部逻辑（Phase 1）。
4. **改造须带测试**：Phase 2 动执行器/共享库时，每项须有独立测试（单元 + 一次真实跑通）后才并入。
5. **看护模型**：一键启动（`run_all.py`）+ 代理（WorkBuddy）逐流程看护，非自治 cron；失败分类 `RECOVERABLE` 预算内重试 / `NEEDS_LOGIN` @人 / `UNKNOWN` 升级。
