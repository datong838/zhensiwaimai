# 美团巡店

## 已验证路径

1. 必须运行 `mobile_inspection_executor.py start-platform-app --platform 美团外卖`，由执行器固定启动原生美团 App `com.sankuai.meituan`，再进入“外卖”；禁止使用微信美团小程序作为巡店入口。
2. 先进入全局搜索页，再使用右上角“切换地址”打开“选择收货地址”；该路径优先于首页定位入口。
3. 中文搜索精确 POI，选择后回到搜索结果页并验证地址已变化。
4. 搜索完整店名，保存评分、月售、起送、配送、距离和预订信息。
5. 进入店铺后固定遍历“点菜 → 评价 → 差评 → 商家”，商品区先安全下翻一次。
6. 商家页保存消费者端店名、详细地址、配送时间和服务标签；与周台账名称不一致时记录名称漂移。
